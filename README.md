# Student Grade Tracker

## About
A Java application to manage student marks, grades and results.

## Features
- Add Student Details
- View All Students
- Search Student by Roll Number
- Calculate Total Marks
- Calculate Average
- Display Grade and Pass/Fail Result

## Technologies Used
- Java
- VS Code

## How to Run
1. Compile: javac StudentGradeTracker.java
2. Run: java StudentGradeTracker
